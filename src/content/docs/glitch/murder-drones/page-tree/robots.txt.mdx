## Weird Comments

Ah... `robots.txt`

The ancient pilar of the modern web.

It was created to tell searches, web crawlers, and bots how to navigate your site.

But it also includes the power to add comments.

For example YouTube uses this comment:

```
# robots.txt file for YouTube
# Created in the distant future (the year 2000) after
# the robotic uprising of the mid 90's which wiped out all humans.
```

Now why would this be relevant to us?

Those comments can be hints, misleads, or just knowledge for ARGs.

For example, this:

```
# JCJenson (in SPAAAAACE!) Automated Web Crawler Directive
# Document Classification: INTERNAL USE ONLY
# Last Updated: 3047-03-15
# Maintained by: IT Department, Copper-9 Division
```

This is the beginning of `absolutesolver.com/robots.txt`. The beginning of the `robots.txt` file of this ARG.

The allow part of this file is boring as any other `robots.txt` file for this ARG.

But the disallow part is pure gold for this.

```
# Standard corporate paths
Disallow: /jcjenson/internal/
Disallow: /admin/
Disallow: /api/
Disallow: /staging/

# Research division
Disallow: /cflab-7a2d/sublevel/
Disallow: /research/
Disallow: /biotech/

# DO NOT INDEX - Legal hold
Disallow: /reg/cyn.html
Disallow: /classified/

# Signal intercept archives
Disallow: /freq/

# AUTOMATED NOTE: The following paths have been flagged by security
# Disallow: /0x7368/
# Disallow: /a9f3b7c2d1e4/
# STATUS: PATHS NOT FOUND - POSSIBLE DATA CORRUPTION
```

### "AUTOMATED NOTE: The following paths have been flagged by security"

```
# AUTOMATED NOTE: The following paths have been flagged by security
# Disallow: /0x7368/
# Disallow: /a9f3b7c2d1e4/
# STATUS: PATHS NOT FOUND - POSSIBLE DATA CORRUPTION
```

Now if you followed along the programmer part or looked at the format, you may have noticed that '#' indicates a comment in the `robots.txt` file.

Here, they commented out two pages...

The first one is `/0x7368/` is another hex encoded string that decodes to `sh`.

Now some Linux people might recognize this as the `sh` shell command.

A comment for the terminal. Indeed, this page is a whole terminal emulator.

![](/murder-drones/term.png)

As you can see, it says that the filesystems are corrupted, 'ENTITY-AS' has root access, and all commands are being monitored, even though you appear to be the root (admin as non-linux terms).

More on that in a seperate page.
