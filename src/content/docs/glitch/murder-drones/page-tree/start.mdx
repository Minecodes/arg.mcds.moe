## The Solver - A look into the console

Now, let's take a look at the console I thought.

![](/murder-drones/start-console.png)

Interesting... They used CSS over `console.log`.

There also was my next clue. A base64 encoded string.

`TG9vayB3aGVyZSB0aGV5IHRlbGwgeW91IG5vdCB0byBsb29rLiAvcm9ib3RzLnR4dA==`

It decodes to the following: `Look where they tell you not to look. /robots.txt`

Now for those that are not that familiar with programmer terms:

 - `base64` - A format to encode binary data as text. Used for HTML embedded image files, data transportation, and more.
 - `/robots.txt` - A file that contains instructions for web crawlers (Google, Bing, ChatGPT Search & co). Used to prevent crawling of sensitive or restricted content.

Throughout my whole research, I used CyberChef a lot.

It helps decoding, encoding, decrypting, encrypting, cyphering, and analyzing data.

It also helps detecting the type of string you are dealing with. Like base64, hex, ASCII, UTF-8, and more.
